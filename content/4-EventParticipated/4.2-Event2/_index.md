# Summary Report: GenAI-powered App-DB Modernization Workshop

## Event Information

- **Event:** GenAI-powered App-DB Modernization Workshop
- **Date:** June 2026
- **Organizer:** Amazon Web Services (AWS)
- **Role:** Participant

---

## Event Objectives

The workshop focused on introducing modern application modernization strategies using Generative AI and AWS cloud services.

The objectives of the event included:

- Understanding modern cloud-native application architecture.
- Learning Domain-Driven Design (DDD) for large-scale software systems.
- Exploring Event-Driven Architecture.
- Understanding serverless computing and modern AWS compute services.
- Discovering how Amazon Q Developer accelerates software development with Generative AI.

---

## Main Topics

### 1. Modernizing Legacy Applications

The speakers explained the common challenges faced by legacy applications, including:

- Slow software delivery.
- Difficult maintenance.
- High infrastructure costs.
- Security and compliance risks.

The workshop introduced modernization strategies to migrate traditional applications into cloud-native architectures running on AWS.

---

### 2. Domain-Driven Design (DDD)

A major topic of the workshop was Domain-Driven Design.

The speakers demonstrated how Event Storming can help identify business processes, domain events, bounded contexts, and relationships between services before writing code.

This approach allows development teams to design software based on business requirements rather than technical implementation.

---

### 3. Event-Driven Architecture

Another important session focused on Event-Driven Architecture.

The workshop explained several communication patterns:

- Publish / Subscribe
- Point-to-Point Messaging
- Event Streaming

The speakers also compared synchronous and asynchronous communication, highlighting how event-driven systems improve scalability, flexibility, and fault tolerance.

---

### 4. Modern AWS Compute Services

The workshop compared different AWS compute options, including:

- Amazon EC2
- Amazon ECS
- AWS Fargate
- AWS Lambda

Each service has different use cases depending on application architecture, operational complexity, and scalability requirements.

Special attention was given to AWS Lambda as a serverless computing platform that automatically scales and reduces operational overhead.

---

### 5. Amazon Q Developer

The final technical session introduced Amazon Q Developer.

This AI-powered assistant supports developers throughout the Software Development Life Cycle (SDLC), including:

- Code generation
- Code explanation
- Refactoring
- Application modernization
- AWS best-practice recommendations

The speakers demonstrated how Amazon Q can improve developer productivity while reducing repetitive work.

---

## Knowledge Gained

After attending the workshop, I learned several valuable concepts:

- Modern application modernization strategies on AWS.
- Practical use of Domain-Driven Design.
- Event-Driven Architecture for loosely coupled systems.
- Differences between EC2, ECS, Fargate, and Lambda.
- Practical applications of Amazon Q Developer in software development.

## Applying to My Projects

The knowledge gained from this workshop can be directly applied to my cloud projects.

Some practical applications include:

- Designing scalable microservice architectures using Domain-Driven Design.
- Building asynchronous systems with Event-Driven Architecture.
- Using AWS Lambda to implement serverless business logic.
- Monitoring cloud applications using Amazon CloudWatch.
- Applying Amazon Q Developer to improve development productivity and code quality.
- Designing AWS architectures following the AWS Well-Architected Framework.

## Event Experience

Participating in the GenAI-powered App-DB Modernization Workshop gave me a deeper understanding of how modern cloud applications are designed, deployed, and maintained on AWS.

The discussions about Domain-Driven Design helped me understand the importance of modeling business domains before implementing software solutions.

The Event-Driven Architecture session complemented what I had previously learned about Amazon SQS and AWS Lambda, providing practical examples of asynchronous communication between distributed services.

Another highlight was learning how Amazon Q Developer leverages Generative AI to assist developers during coding, debugging, documentation, and application modernization.

Overall, the workshop not only expanded my technical knowledge but also provided practical insights into designing scalable, maintainable, and cloud-native applications using AWS services.
