# Summary Report: AWS Student Builder Group Meetup – Build Voice Agent

## Event Information

- **Event:** AWS Student Builder Group Meetup – Build Voice Agent
- **Date:** Saturday, May 30, 2026
- **Time:** 09:00 AM
- **Venue:** AWS Vietnam Office, 26th Floor, Bitexco Financial Tower, Ho Chi Minh City
- **Role:** Participant

---

## Event Objectives

The meetup focused on introducing modern AI Agent technologies on AWS and helping participants understand how to design, build, and deploy Voice AI applications using AWS services.

The main objectives included:

- Understanding the concept of AI Agents and Voice Agents.
- Exploring Amazon Bedrock AgentCore.
- Learning the basic architecture of Voice Agent applications.
- Sharing best practices for scaling AI Agent systems in production.

---

## Main Topics

### Introduction to Voice AI

The speakers introduced the concept of Voice Agents and explained how conversational AI is becoming an important component in modern applications.

Participants learned how speech recognition, natural language understanding, and response generation work together to build intelligent voice assistants.

---

### Amazon Bedrock AgentCore

One of the most interesting sessions introduced Amazon Bedrock AgentCore.

The presentation demonstrated how developers can build AI Agents capable of understanding user intent, interacting with enterprise systems, and executing business workflows using foundation models available through Amazon Bedrock.

---

### Voice Agent Architecture on AWS

The speakers explained a typical Voice AI architecture, including:

- Client Applications
- Amazon API Gateway
- AWS Lambda
- Amazon Bedrock
- Amazon S3
- Amazon DynamoDB
- Amazon CloudWatch

The architecture emphasized scalability, serverless computing, and event-driven communication.

---

### Best Practices

Several practical recommendations were shared during the meetup:

- Design modular AI Agent workflows.
- Monitor AI applications using Amazon CloudWatch.
- Secure API endpoints with IAM and authentication mechanisms.
- Optimize operational costs by leveraging serverless services.
- Build scalable architectures capable of handling large numbers of concurrent users.

---

## Key Takeaways

After attending the meetup, I gained several valuable insights:

- A better understanding of the overall architecture of Voice AI applications.
- Practical knowledge of Amazon Bedrock AgentCore.
- The importance of serverless services such as AWS Lambda in AI applications.
- Better understanding of event-driven architectures when integrating AI services.
- Awareness of best practices for building scalable AI Agent systems.

---

## Applying to My Projects

The knowledge gained from this meetup can be applied in several ways:

- Designing AI-powered applications using Amazon Bedrock.
- Building serverless backend services with AWS Lambda.
- Applying event-driven architecture to AI workflows.
- Monitoring cloud applications with Amazon CloudWatch.
- Designing scalable cloud-native systems on AWS.

## Event Experience

Attending the AWS Student Builder Group Meetup gave me the opportunity to learn directly from AWS community speakers and interact with students who share the same interest in cloud computing and artificial intelligence.

The session on Amazon Bedrock AgentCore helped me understand how generative AI services can be integrated into modern cloud applications. I also gained practical knowledge about designing Voice AI architectures using AWS serverless technologies.

Besides the technical sessions, the meetup provided a great opportunity to network with other AWS learners and exchange experiences related to cloud architecture, AI applications, and career development.

Overall, this event strengthened my understanding of modern AI application development and motivated me to continue exploring AWS AI services.
