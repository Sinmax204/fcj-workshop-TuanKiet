# Blogs Posted

During my internship, I actively explored AWS technologies and documented my learning by publishing technical articles in the **AWS Study Group** community. Writing these blogs not only reinforced my understanding of cloud computing concepts but also improved my research, technical writing, and knowledge-sharing skills.

The two articles focus on key areas of AWS cloud architecture. The first discusses **Event-Driven Architecture** using serverless services, while the second introduces the fundamentals of **Amazon Virtual Private Cloud (Amazon VPC)** for designing secure and scalable cloud networks.

---

## [Blog 1 – Building Event-Driven Applications on AWS](3.1-Blog1/)

This article explains the fundamentals of **Event-Driven Architecture (EDA)** and demonstrates how AWS services such as **Amazon API Gateway**, **Amazon SQS**, **AWS Lambda**, **Amazon DynamoDB**, **Amazon CloudWatch**, and **Amazon SNS** can be integrated to build loosely coupled and highly scalable cloud-native applications.

The blog also discusses the advantages of asynchronous communication, automatic scaling, fault tolerance, monitoring, and practical scenarios where event-driven architecture can improve application performance and reliability.

---

## [Blog 2 – Amazon VPC: Building Secure and Scalable Cloud Networks](3.2-Blog2/)

This article introduces the core concepts of **Amazon Virtual Private Cloud (Amazon VPC)** and explains the roles of networking components such as **Public Subnets**, **Private Subnets**, **Internet Gateway**, **NAT Gateway**, **Security Groups**, and **Network ACLs**.

In addition, the article presents best practices for designing secure, highly available, and scalable network architectures on AWS, providing a solid foundation for deploying enterprise cloud applications.

---

Through writing these technical blogs, I was able to consolidate the knowledge acquired during my internship while improving my ability to research, document, and communicate technical topics. Sharing these articles with the AWS Study Group community also allowed me to contribute learning resources and engage with other cloud enthusiasts.
