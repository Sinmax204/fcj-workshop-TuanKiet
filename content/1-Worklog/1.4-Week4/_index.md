### Week 4 Objectives:

* Understand the fundamentals of Amazon Relational Database Service (Amazon RDS).
* Learn about relational databases and database management on AWS.
* Create and configure an Amazon RDS database instance.
* Practice connecting applications to Amazon RDS.

### Week 4 Achievements:

* Understood the architecture and key features of Amazon RDS.

* Successfully created and configured an Amazon RDS database instance.

* Configured Security Groups and networking settings for secure database connectivity.

* Connected to the database using a database management tool such as MySQL Workbench.

* Created databases, tables, and executed basic SQL queries.
