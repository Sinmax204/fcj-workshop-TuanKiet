### Week 2 Objectives:

* Understand the basic concepts of Amazon VPC and AWS networking.
* Learn how to create and configure a Virtual Private Cloud (VPC).
* Practice configuring subnets, route tables, and Internet Gateway.
* Deploy an Amazon EC2 instance within a VPC.
