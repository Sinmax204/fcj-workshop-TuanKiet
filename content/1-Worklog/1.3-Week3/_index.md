### Week 3 Objectives:

* Understand the fundamentals of Amazon Simple Storage Service (Amazon S3).
* Learn how to create and manage Amazon S3 buckets and objects.
* Configure permissions and access control for Amazon S3.
* Practice hosting a static website using Amazon S3.

### Tasks to be carried out this week:

| Day | Task | Start Date | Completion Date | Reference Material |
| --- | ---- | ---------- | --------------- | ------------------ |
| 1 | Learn the basic concepts of Amazon S3, including buckets, objects, object keys, and storage classes. | 01/05/2026 | 01/05/2026 | <https://cloudjourney.awsstudygroup.com/> |
| 2 | Create an Amazon S3 bucket and practice uploading, downloading, renaming, and deleting objects. | 02/05/2026 | 02/05/2026 | <https://cloudjourney.awsstudygroup.com/> |
| 3 | Learn how Bucket Policies, IAM Policies, and Access Control Lists (ACLs) are used to manage access to Amazon S3. | 03/05/2026 | 03/05/2026 | <https://cloudjourney.awsstudygroup.com/> |
| 4 | Enable bucket versioning and practice restoring previous versions of objects. | 04/05/2026 | 04/05/2026 | <https://cloudjourney.awsstudygroup.com/> |
| 5 | Configure an Amazon S3 bucket for Static Website Hosting and deploy website files. | 05/05/2026 | 05/05/2026 | <https://cloudjourney.awsstudygroup.com/> |
| 6 | Review Amazon S3 concepts and complete the assigned laboratory exercises. | 06/05/2026 | 06/05/2026 | <https://cloudjourney.awsstudygroup.com/> |

### Week 3 Achievements:

* Understood the architecture and key concepts of Amazon S3.

* Successfully created and managed Amazon S3 buckets.

* Uploaded, downloaded, renamed, and deleted objects in Amazon S3.

* Configured Bucket Policies, IAM Policies, and Access Control Lists (ACLs) to manage access permissions.

* Enabled bucket versioning and restored previous versions of stored objects.

* Successfully hosted a static website using Amazon S3.

* Completed all Week 3 hands-on laboratory exercises.

* Improved practical knowledge of AWS storage services and data management.
